# Borang Permohonan Ahli - User Guide

## Overview
Borang Permohonan Ahli adalah borang permohonan keahlian berasaskan web untuk Dewan Perniagaan Melayu Malaysia (DPMM) Negeri Johor. Borang ini membolehkan individu memohon keahlian DPMM Negeri Johor secara dalam talian.

## 1. Getting Started

### System Requirements
- Web browser (Chrome, Firefox, Safari, Edge)
- Stable internet connection
- Valid IC number
- Business registration information (if applicable)

### Access URL
- Production: `https://dpmmjohor.github.io/SISTEM-AHLI-DPMM-JOHOR/borang.html`
- Development: Contact administrator for local development URL

## 2. Form Overview

### Form Purpose
The borang permohonan ahli collects information for membership application to DPMM Negeri Johor.

### Form Sections
1. **Personal Information**: Name, IC number, contact details
2. **Business Information**: Business type, business registration, business address
3. **Payment Information**: Payment method, payment details
4. **Declaration**: Applicant declaration and consent

### Form Validation
- All required fields must be filled
- IC number must be valid Malaysian IC format
- Phone number must be valid Malaysian format
- Email address must be valid format
- Business registration number must be valid (if applicable)

## 3. Personal Information

### Fields Required

#### Full Name (Nama Penuh)
- **Description**: Your full name as per IC
- **Format**: First name and last name
- **Example**: Ahmad bin Ali
- **Validation**: Required field

#### IC Number (Nombor Kad Pengenalan)
- **Description**: Malaysian IC number
- **Format**: XXXXXX-XX-XXXX (12 digits with dashes)
- **Example**: 123456-12-1234
- **Validation**: Required field, must be valid IC format

#### Phone Number (Nombor Telefon)
- **Description**: Contact phone number
- **Format**: Malaysian mobile number (01X-XXXXXXX)
- **Example**: 012-3456789
- **Validation**: Required field, must be valid phone format

#### Email Address (Alamat E-mel)
- **Description**: Contact email address
- **Format**: Valid email format
- **Example**: ahmad@example.com
- **Validation**: Required field, must be valid email format

#### Address (Alamat)
- **Description**: Residential or business address
- **Format**: Street address, city, state, postal code
- **Example**: 123 Jalan Utama, Johor Bahru, 80000
- **Validation**: Required field

### Step-by-Step Personal Information Entry

1. **Enter Full Name**
   - Type your full name as per IC
   - Ensure spelling is correct
   - Use proper capitalization

2. **Enter IC Number**
   - Type your IC number with dashes
   - Format: XXXXXX-XX-XXXX
   - Verify number is correct

3. **Enter Phone Number**
   - Type your mobile phone number
   - Format: 01X-XXXXXXX
   - Ensure number is active

4. **Enter Email Address**
   - Type your email address
   - Ensure email is active
   - Use professional email if possible

5. **Enter Address**
   - Type your complete address
   - Include street, city, state, postal code
   - Ensure address is accurate

## 4. Business Information

### Fields Required

#### Business Type (Jenis Perniagaan)
- **Description**: Type of business
- **Options**: Individual, Partnership, Company
- **Validation**: Required field

#### Business Name (Nama Perniagaan)
- **Description**: Business name
- **Format**: Registered business name
- **Example**: Ahmad Enterprise
- **Validation**: Required field for Partnership/Company

#### Business Registration Number (Nombor Pendaftaran Perniagaan)
- **Description**: SSM registration number
- **Format**: Valid SSM format
- **Example**: 123456-A
- **Validation**: Required field for Partnership/Company

#### Business Address (Alamat Perniagaan)
- **Description**: Business address
- **Format**: Street address, city, state, postal code
- **Example**: 456 Jalan Bisnes, Johor Bahru, 80000
- **Validation**: Required field for Partnership/Company

### Step-by-Step Business Information Entry

1. **Select Business Type**
   - Choose from dropdown: Individual, Partnership, Company
   - Select the option that best describes your business

2. **Enter Business Name** (if Partnership/Company)
   - Type your registered business name
   - Ensure name matches SSM registration
   - Use proper capitalization

3. **Enter Business Registration Number** (if Partnership/Company)
   - Type your SSM registration number
   - Format: XXXXXX-A
   - Verify number is correct

4. **Enter Business Address** (if Partnership/Company)
   - Type your business address
   - Include street, city, state, postal code
   - Ensure address is accurate

## 5. Payment Information

### Fields Required

#### Payment Method (Kaedah Pembayaran)
- **Description**: Preferred payment method
- **Options**: Online Banking, Cash, Cheque
- **Validation**: Required field

#### Payment Amount (Jumlah Pembayaran)
- **Description**: Membership fee amount
- **Format**: RM XXX.XX
- **Example**: RM 100.00
- **Validation**: Required field, must be valid amount

#### Payment Reference (Rujukan Pembayaran)
- **Description**: Payment reference number
- **Format**: Transaction reference
- **Example**: REF123456
- **Validation**: Required field for online banking

### Step-by-Step Payment Information Entry

1. **Select Payment Method**
   - Choose from dropdown: Online Banking, Cash, Cheque
   - Select your preferred payment method

2. **Enter Payment Amount**
   - Type the membership fee amount
   - Format: RM XXX.XX
   - Verify amount is correct

3. **Enter Payment Reference** (if Online Banking)
   - Type your transaction reference number
   - Format: Bank transaction reference
   - Ensure reference is accurate

## 6. Submission

### Review Before Submission
Before submitting, review all information:
- Personal information is correct
- Business information is accurate (if applicable)
- Payment information is complete
- All required fields are filled

### Submit Application
1. Click "Hantar Permohonan" (Submit Application) button
2. System will validate all fields
3. If validation passes, application will be submitted
4. If validation fails, error messages will appear
5. Correct errors and resubmit

### Validation Errors
Common validation errors:
- **Required field missing**: Fill in all required fields
- **Invalid IC format**: Use correct IC format (XXXXXX-XX-XXXX)
- **Invalid phone format**: Use correct phone format (01X-XXXXXXX)
- **Invalid email format**: Use correct email format
- **Invalid amount format**: Use correct amount format (RM XXX.XX)

### Submission Confirmation
After successful submission:
- Confirmation message will appear
- Application reference number will be generated
- You will receive email confirmation
- Application will be reviewed by DPMM

## 7. Confirmation

## 8. FAQ

### General Questions

**Q: What if I make a mistake in my application?**
A: Contact DPMM Negeri Johor office with your reference number to request corrections.

**Q: Can I save my application and complete it later?**
A: No, the form must be completed in one session. Ensure you have all information ready before starting.

**Q: What if I don't have a business?**
A: Select "Individual" as business type. Business information is not required for individual applicants.

### Personal Information

**Q: What if my IC number format is different?**
A: Use the standard Malaysian IC format (XXXXXX-XX-XXXX). Contact administrator if you have a different format.

**Q: Can I use a different phone number?**
A: Use your active mobile phone number for communication purposes.

**Q: What if I don't have an email address?**
A: Email address is required for application confirmation. Create an email account before applying.

### Business Information

**Q: What if my business is not registered with SSM?**
A: Select "Individual" as business type. SSM registration is required for Partnership/Company applicants only.

**Q: Can I apply as an individual and later upgrade to Partnership/Company?**
A: Contact DPMM Negeri Johor office for membership upgrade information.

**Q: What if my business address is the same as my residential address?**
A: You can use the same address for both residential and business information.

### Payment Information

**Q: What payment methods are accepted?**
A: Online Banking, Cash, and Cheque are accepted.

**Q: What is the membership fee amount?**
A: Contact DPMM Negeri Johor office for current membership fee information.

**Q: Can I pay in installments?**
A: Contact DPMM Negeri Johor office for installment payment options.

### Submission

**Q: What if my submission fails?**
A: Check for validation errors, correct them, and resubmit. Contact administrator if issue persists.

**Q: How long does it take to process my application?**
A: Processing time varies. Contact DPMM Negeri Johor office for current processing times.

**Q: What if I don't receive email confirmation?**
A: Check your spam folder. Contact DPMM Negeri Johor office if you don't receive confirmation within 24 hours.

### Technical Issues

**Q: What if the form is not loading?**
A: Refresh the page, check your internet connection, try a different browser.

**Q: What if I see an error message?**
A: Note the error message and contact DPMM Negeri Johor office with details.

**Q: Can I use the form on mobile?**
A: Yes, the form is responsive and works on mobile devices.

## 11. Troubleshooting

### Form Issues
- **Problem**: Form not loading
- **Solution**: Refresh page, check internet connection, try different browser

- **Problem**: Fields not accepting input
- **Solution**: Refresh page, clear browser cache, try different browser

- **Problem**: Submit button not working
- **Solution**: Check all required fields, fix validation errors, refresh page

### Validation Issues
- **Problem**: IC number validation failing
- **Solution**: Check IC format, ensure dashes are included, verify number is correct

- **Problem**: Phone number validation failing
- **Solution**: Check phone format, ensure Malaysian format, verify number is correct

- **Problem**: Email validation failing
- **Solution**: Check email format, ensure valid email, verify email is correct

### Submission Issues
- **Problem**: Submission failing
- **Solution**: Check all required fields, fix validation errors, check internet connection

- **Problem**: No confirmation after submission
- **Solution**: Wait a few minutes, check email, contact support if no confirmation
