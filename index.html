📋 Panduan Tugas Bulanan

1
Semak Senarai Ahli
Buka Senarai Ahli dan pastikan semua maklumat ahli adalah terkini. Kemaskini sebarang maklumat yang tidak lengkap atau tidak tepat.
2
Semak Status Yuran
Periksa Yuran Tracker untuk melihat ahli yang belum menjelaskan yuran. Kenal pasti keutamaan tindakan susulan.
3
Semak Status SSM
Periksa SSM Tracker untuk ahli yang SSM-nya akan tamat tempoh dalam masa 6 bulan. Hantar peringatan tepat pada masanya.
4
Hantar Notis Follow Up
Gunakan halaman Follow Up dan Template Mesej untuk menghantar notis WhatsApp kepada ahli yang memerlukan tindakan. Gunakan Template 1 untuk notis pertama, Template 2 untuk peringatan kedua.
5
Kemaskini Data & Sandaran
Selepas menerima bayaran atau maklumat baru, kemaskini rekod ahli. Lakukan sandaran data secara berkala melalui halaman Sandaran Data.
6
Laporan Bulanan
Cetak atau eksport laporan dari Dashboard untuk dibentangkan dalam mesyuarat. Gunakan butang Cetak dalam setiap halaman untuk laporan bercetak.

Panduan Penggunaan Sistem

DASHBOARD

Papan pemuka utama menunjukkan ringkasan keseluruhan — jumlah ahli, status yuran, SSM kritikal, dan graf peratusan.

  • Klik "Jana Laporan" untuk hasilkan laporan PDF lengkap
  • Klik "FOLLOW UP" untuk lihat ahli yang perlu tindakan segera
  • Kad KPI di atas boleh diklik untuk navigasi pantas
SENARAI AHLI
  • Klik baris ahli untuk lihat butiran penuh
  • Butang "Edit Ahli" dalam modal untuk kemaskini maklumat
  • Gunakan bar carian dan penapis daerah/fasal untuk tapis rekod
  • Butang "Eksport" untuk muat turun sebagai CSV, PDF atau Imej
  • Butang "+ Tambah Ahli" untuk daftar ahli baharu
YURAN TRACKER
  • Lihat status bayaran yuran mengikut fasal dan daerah
  • Rekod bertanda BELUM BAYAR perlu tindakan susulan
  • Klik nama ahli untuk terus ke modal butiran dan rekod bayaran
SSM TRACKER
  • Rekod SSM disusun mengikut kumpulan: LUPUT, HAMPIR LUPUT, SAH
  • Tempoh "Hampir Luput" = dalam masa 180 hari
  • Klik baris ahli untuk kemaskini tarikh SSM melalui butang Edit
FOLLOW UP
  • Tiga senarai tindakan: Yuran Belum Bayar, SSM Kritikal, Data Tidak Lengkap
  • Klik "WA" untuk hantar mesej WhatsApp dengan template pilihan
  • Klik "Salin Mesej" untuk salin teks ke clipboard
  • Butang "Eksport" hasilkan laporan Follow Up dalam format landskap A4
TEMPLATE MESEJ
  • Klik "Edit" pada mana-mana kad template untuk ubahsuai
  • Klik "+ Tambah Template" untuk cipta template baharu
  • Placeholder yang tersedia: [NAMA PIC], [NO. AHLI], [NAMA SYARIKAT], [TARIKH LUPUT SSM]
  • Template disimpan secara automatik dalam pelayar (localStorage)

Soalan Lazim (FAQ)

• Data ahli tidak kelihatan / kosong selepas log masuk
Sistem akan cuba memuat data dari pangkalan data Supabase. Sekiranya sambungan gagal, ralat akan dipaparkan di skrin log masuk. Pastikan anda mempunyai sambungan internet yang stabil. Cuba muat semula halaman (F5) dan log masuk semula. Sekiranya masalah berterusan, hubungi pentadbir sistem.
• Bagaimana cara kemaskini yuran ahli selepas bayaran diterima?
Klik pada baris ahli dalam Senarai Ahli → klik butang "Edit Ahli" → tukar status "Yuran Tahunan" kepada "Telah Bayar" → klik "Simpan". Rekod pembayaran akan dikemaskini secara automatik berserta tarikh hari ini.
• Apakah perbezaan antara Fasal 6.2.1 dan 6.2.4?
Fasal 6.2.1 adalah untuk ahli bertaraf Enterprise (ENT) — yuran tahunan RM 50. Fasal 6.2.4 adalah untuk ahli bertaraf Syarikat Sendirian Berhad (Sdn Bhd) — yuran tahunan RM 150. Status ini menentukan yuran pendaftaran dan yuran tahunan secara automatik.
• Mengapa SSM ahli tidak muncul dalam SSM Tracker?
SSM Tracker hanya memaparkan ahli yang mempunyai No. SSM DAN Tarikh Luput SSM yang diisi. Sekiranya salah satu medan ini kosong, ahli tersebut tidak akan tersenarai. Kemaskini maklumat SSM melalui butang Edit dalam modal butiran ahli.
• Bagaimana cara menghantar mesej WhatsApp secara pukal kepada ahli?
Pergi ke tab Follow Up → pilih senarai ahli yang dikehendaki → klik butang "WA" pada baris ahli → pilih template mesej → semak kandungan → klik "Buka WhatsApp". Mesej perlu dihantar satu persatu secara manual melalui WhatsApp Web atau aplikasi WhatsApp.
• Adakah data disimpan secara selamat?
Data ahli disimpan dalam pangkalan data Supabase yang dilindungi dengan enkripsi SSL. Template mesej dan log aktiviti disimpan dalam localStorage pelayar anda — data ini hanya boleh diakses dari peranti yang sama. Lakukan Backup secara berkala melalui tab Back Up untuk memastikan data selamat.
• Bagaimana cara menambah pengguna baharu?
Hanya Admin boleh menambah pengguna. Log masuk sebagai admin → pergi ke Panel Admin → klik "+ Tambah Pengguna" → isi ID, nama, kata laluan, dan peranan → klik "Simpan". Pengguna baharu boleh terus log masuk dengan kelayakan tersebut.
• Apakah yang perlu dilakukan jika laporan PDF tidak dapat dicetak?
Pastikan pelayar anda membenarkan pop-up dari aplikasi ini. Di Chrome: klik ikon di bar alamat → Tetapan Tapak → Pop-up dan ubah hala → Benarkan. Kemudian cuba jana laporan semula. Untuk hasil terbaik, gunakan Google Chrome atau Microsoft Edge.
• Bagaimana cara membuat Backup data?
Pergi ke tab Back Up → klik "Backup Sekarang" untuk muat turun salinan data dalam format JSON. Simpan fail ini di lokasi yang selamat. Sekiranya data hilang, hubungi pentadbir sistem untuk pulihkan dari Supabase.
• Adakah sistem ini boleh digunakan pada telefon bimbit?
Ya, sistem ini responsif dan boleh digunakan pada telefon bimbit. Klik ikon menu di bahagian bawah kiri untuk buka menu navigasi. Untuk pengalaman terbaik, disyorkan menggunakan tablet atau komputer desktop terutamanya untuk operasi seperti menjana laporan dan eksport PDF.
